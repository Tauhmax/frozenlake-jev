# 轨迹决策与规划复杂度分析

分析对象是每局实际访问的决策状态。每步的 action 与同一步有限时域 Bellman 最优动作集合比较；正确表示命中任一并列最优动作。只统计 `solvable_within_budget=true` 的状态，避免已无可行到达路径时所有动作 Q 值为零产生虚高准确率。掉洞和超时是终局结果，不再额外计为下一步决策。

复杂度指标取自地图图结构：当前状态到 G 的最短安全路径长度（有效规划距离）；绕行量 = 最短路径长度 − 曼哈顿距离；地图尺寸。绕行量反映障碍物造成的非直线路径，但它不能概括所有拓扑或搜索难点。步数分组表示执行中的决策深度，后续步数只来自仍在进行的局，因此会有幸存者偏差。

共同起点的准确率随绕行量增加而下降：0.8B 从直线路径的 52.8% 降到绕行 3+ 的 30.0%；4B 从 75.7% 降到 42.5%。按起点距离分组也从 1–2 步的 71.5% / 92.7% 降到 9+ 步的 39.8% / 58.5%。这表示当前地图集上障碍绕行和远距离状态更难。

同一地图在不同模型下走过的后续状态不同；完整轨迹的距离与绕行分组是各自访问状态上的描述性准确率。只有第 1 步是严格配对的共同起点。模型为 0.8B BF16、4B NF4，精度差异也在比较中。

## 解释边界

判断时优先看样本量 N 和唯一最优子集。全部最优动作准确率会受到 Bellman 并列动作影响；唯一最优准确率更直接，但样本会减少。离终点距离较远的困难地图更容易在早期终止，造成后续步数分组样本稀疏。按步数出现的变化不能单独解释为“规划越深越难”。

该实验衡量的是每个实际访问状态下的单步动作是否为全局有限时域最优动作；它不是对模型内部推理深度的直接测量。更多地图、控制分支数/捷径数的地图对照，以及候选动作置换实验，可进一步分离规划能力与标签/方向偏好。

输入日志：`results/episodes/qwen35-max30.jsonl`、`results/episodes/qwen4b-max30.jsonl`。两份日志含真实状态序列、模型动作和概率、Q 值及最优动作。
